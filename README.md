# Model Comparison using Machine Learning

This project compares multiple machine learning models on the Breast Cancer dataset.

## Models Used
- Logistic Regression
- Decision Tree
- Random Forest
- K-Nearest Neighbors

## Evaluation Metrics
- Accuracy
- Precision
- F1 Score

## Tools & Libraries
- Python
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

## Objective
To compare performance of different ML models and visualize feature importance.
